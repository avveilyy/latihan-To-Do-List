
To-Do List

1.Fitur

* Menambahkan tugas baru
* Menambahkan tugas dengan menekan tombol Enter
* Mencari tugas tertentu
* Menandai tugas sebagai selesai
* Menghapus tugas
* Memfilter tugas berdasarkan:
    * Semua
    * Aktif
    * Selesai
* Menampilkan jumlah tugas yang tersisa
* Menampilkan empty state ketika tidak ada tugas
* Responsive untuk ukuran layar yang lebih kecil

2.Teknologi

* HTML — Struktur website
* CSS — Styling dan responsive layout
* JavaScript — Mengatur fitur dan interaksi website
* Font Awesome — Icon pada interface

3.Desain

Website menggunakan desain yang sederhana dan clean dengan:

* Background cream #FFF5E1
* Text dark blue #29375A
* Accent dark red #7C0000
* Container berwarna putih
* Rounded corners dan soft shadow

Container utama menggunakan lebar 560px dengan background putih, rounded corners, dan shadow.

5.Cara Kerja

Menambahkan Tugas

Pengguna dapat mengetik tugas pada input kemudian menekan tombol Add + atau tombol Enter untuk menambahkan tugas ke dalam daftar.

Menyelesaikan Tugas

Checkbox dapat digunakan untuk menandai tugas sebagai selesai. Setelah dicentang, teks tugas akan berubah menjadi coret dan jumlah tugas yang tersisa akan diperbarui.

Menghapus Tugas

Tombol Hapus digunakan untuk menghapus tugas dari daftar. Setelah tugas dihapus, jumlah tugas dan empty state akan diperbarui.

Mencari Tugas

Fitur search digunakan untuk mencari tugas berdasarkan kata kunci. Jika tidak ada tugas yang sesuai, akan muncul pesan bahwa tugas tidak ditemukan.
